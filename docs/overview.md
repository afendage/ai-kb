# PAX User Simulator 知识库

## 项目目的

`PAX User Simulator` 是一个基于 Python + Selenium 的用户行为模拟框架。它的主要目标是：

- 自动化注册测试用户
- 模拟真实用户在 UAT 页面上的浏览行为
- 为 QA 回归、站点验证和选择器调试提供可重复的测试流程
- 在测试环境中生成测试用户数据并记录运行结果

## 使用场景

- 业务 QA：自动验证注册流程是否可用，并确认页面元素是否正确。
- 回归测试：在页面结构变更后通过脚本快速检查注册和行为流程是否仍然可用。
- 选择器调试：使用 `inspect` 模式检查页面元素选择器，帮助维护 Page Object。
- 自动化数据准备：生成大量测试账号用于后续系统验证或接口测试。
- 浏览行为模拟：模拟实际用户滚动、切换标签和点击操作，验证页面加载与展示逻辑。

## 核心能力

- 支持 Chrome / Edge 浏览器
- 可切换无头模式
- 自动生成 Email、用户名、密码等测试数据
- 记录注册结果到 `artifacts/users.jsonl`
- 失败时自动截图并保存到输出目录
- 支持单次注册、单次行为模拟、注册+模拟组合执行

## 适用对象

- 自动化测试工程师
- QA 负责人
- 前端/后端开发人员，需要验收 UAT 环境的注册与页面体验
- 维护自动化脚本的开发者
